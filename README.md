# Elo — demo (espelho estático)

Este repositório publica, via GitHub Pages, uma demo educacional do Elo com **dados
fictícios** e **sem backend** (tudo roda no navegador, salvo em `localStorage`).

- Não é o sistema em produção. Não requer login. Nada aqui é dado real de clínica ou paciente.
- Gerado a partir do código-fonte em `AlexgrothViro/elo-clinica` (privado), pasta `src/pages/`,
  `src/components/AppShell.tsx` e `src/lib/store.ts` — o mesmo código da rota `/demo` do app
  principal, isolado aqui como site próprio.
- Publicado manualmente (sem CI); para atualizar, gere um novo build e substitua os arquivos.

Site: https://alexgrothviro.github.io/elo-demo/
